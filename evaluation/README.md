# Evaluation boundary

The public tree includes schemas and method boundaries, not the web-derived question corpus.

Evaluate four layers separately:

1. contract: files, schemas, validators, and deterministic routing;
2. semantic: natural-language requests and route quality;
3. human: clarification necessity, burden, correction rate, and usefulness;
4. host: discovery, interaction, recovery, and runtime/version receipts.

Passing a contract test must not be reported as semantic, human, host-native, production, or release evidence.
