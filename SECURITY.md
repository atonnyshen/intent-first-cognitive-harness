# Security

Do not post credentials, private prompts, personal data, unpublished research, or exploitable details in a public issue.

This research preview does not yet publish a repository-specific private security mailbox. Once a repository exists, maintainers should enable GitHub private vulnerability reporting before announcing public releases. Until then, withhold sensitive details and contact the project owner through the private channel used to provide this package.

Security reports are separate from feature requests and provenance questions.
