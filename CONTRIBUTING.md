# Contributing

This is a research preview. Start with a small, reviewable change and describe the user problem it solves.

Before opening a pull request:

- keep private prompts, personal data, raw downloads, and web-derived question text out of the repository;
- add provenance and a compatible licence for any new source or quotation;
- keep facts, assumptions, unknowns, and recommendations separate;
- add or update a deterministic test for contract changes;
- do not claim semantic, human, host-native, or production evidence that was not collected;
- update the public scope or notices when the allowlist changes.

The maintainer may reject a technically working change when its evidence or distribution rights are unclear. Security issues must follow `SECURITY.md`.
