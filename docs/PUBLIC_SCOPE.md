# Public scope

The generated repository is a small installable Skill plus its public contracts. It is not an export of the private research workspace.

Included: the neutral Skill entrypoint, intent and clarification contracts, a question compiler, schemas, evaluation method notes, community files, and security-aware validation scripts.

Excluded: private prompts, phase reports, planning files, raw downloads, unreviewed corpora, historical HC cards, source extracts, model receipts, human observations, and package snapshots.

The exporter is the source of truth for the first public tree. A path is public only when it appears in `open-source/public-release-manifest.yaml` and passes the validator.
